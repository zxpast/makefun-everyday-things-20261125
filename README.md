# Everyday Things, Two Lines — the school bus as a yellow whale

Your entry is `main.ts`: a Node 22 program using only the standard library.
It writes one two-line text to `/output/entry.txt` — no network, no input,
fully deterministic.

Line 1 explains one everyday thing, a school bus, to a 10-year-old in a
single vivid sentence built on one concrete analogy: the bus is a yellow
whale that swallows 40 kids every morning, carries them across town in its
belly, and spits them out at school without ever chewing.

Line 2 says in one sentence why that analogy works: what it maps (both
swallow a crowd whole and carry it somewhere else) and what it leaves out
(a real whale swims in the sea and digests what it eats, while the bus has
a driver, seats, and a door that opens).

## Run it

    node main.ts

It writes `/output/entry.txt` (349 characters, 2 lines, 1 sentence per line)
and refuses to write anything that breaks the gate (1–400 characters,
exactly 2 lines, exactly 1 sentence per line).
